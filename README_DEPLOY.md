# CampBox CSM Hub — V1

## Что уже есть
- Закрытая авторизация Supabase.
- Роли `manager` и `csm`.
- Новые пользователи по умолчанию неактивны.
- Руководитель управляет доступом сотрудников.
- Руководитель добавляет, переименовывает, описывает, сортирует и скрывает функции.
- Лагеря назначаются конкретному CSM.
- Для каждой функции у лагеря отдельный статус, дата обучения, дата активации, причина и комментарий.
- История контактов + следующий шаг + срок.
- Просрочки и лагеря без контакта 14+ дней.
- Дашборд внедрения и обучения.
- Excel-выгрузка по периоду / CSM / функции / просрочкам.
- PWA и мобильная адаптация.

## Быстрый запуск
1. Создай отдельный Supabase-проект для CSM Hub.
2. Выполни `supabase_setup.sql` в SQL Editor.
3. Зарегистрируй первого пользователя через интерфейс.
4. Сделай его руководителем SQL-командой из конца `supabase_setup.sql`.
5. В `index.html` замени:
   - `YOUR_SUPABASE_URL`
   - `YOUR_SUPABASE_PUBLISHABLE_KEY`
6. Опубликуй файлы через GitHub Pages.
7. В Supabase Authentication -> URL Configuration добавь URL GitHub Pages как Site URL и Redirect URL.
8. На телефонах добавляй на экран домой именно прямой URL приложения, а не iframe-страницу Tilda.

## Демо
Пока Supabase не настроен, `index.html` работает в DEMO-режиме. Нажми `Войти` — откроется тестовая база с примерами.


## Новое в V2 — Запуски смен

- отдельный раздел «Запуски смен»;
- дата старта, в том числе статус «Не выяснено»;
- несколько контрольных точек на одну смену;
- просрочки контрольных точек;
- готовность запуска в процентах;
- дашборд ближайших запусков и список лагерей, где дата не выяснена;
- Excel-листы «Запуски смен» и «Точки контроля».

Если база V1 уже создана, повторный запуск обновлённого `supabase_setup.sql` безопасно добавит новые таблицы и политики.

## Новое в V3 — Профиль лагеря

Профиль лагеря вынесен в отдельный слой данных и не влияет на проценты активации функций CampBox.

- руководитель создаёт и редактирует информационные поля;
- типы полей: `Да / Нет / Не выяснено`, текст, число, дата, список вариантов;
- можно добавить отдельное поле «Как работают / детали»;
- CSM заполняет профиль только по своим лагерям, руководитель видит всю базу;
- на дашборде показывается заполненность каждого поля и число лагерей, где информация ещё не выяснена;
- по кнопке можно открыть конкретный список лагерей с пробелами;
- на вкладке «ЛАГЕРЯ» можно фильтровать по информационному полю и значению;
- в карточке лагеря профиль отделён от блока «Функции»;
- в Excel добавлен лист «Профиль лагерей», а значения профиля также попадают в лист «Лагеря».

По умолчанию создаются поля:
- «Работает с несколькими юрлицами?»;
- «Работает с субсидиями?».

Если база V2 уже создана, повторный запуск `supabase_setup.sql` добавит только новые таблицы, RLS-политики, индексы и стартовые поля профиля.
